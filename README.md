# Умная тетрадка

Развивающие игры для 1–4 класса прямо в браузере: математика, логика, русский и белорусский язык, внимательность, творчество, безопасность и ПДД. Котёнок-тамагочи, сундуки с одеждой, котятами и мебелью, уровни, ивенты и таблица лидеров.

**Играть:** https://skr1gun23-ux.github.io/umnaya-tetrad/

Вся игра — один файл `index.html`. Исходники разбиты на части в папке `src/`.
